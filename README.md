# IT Career Switch: Portfolio Projects


## Portfolio Project #1: Gazetteer
The first portfolio project, "Gazetteer," involved creating a map-based app to provide information on countries, specifically focusing on a "mobile-first" development approach. The project used the following tech stack:

* HTML
* CSS
* jQuery
* PHP
* Leafletjs
* Bootstrap

The solution incorporated PHP server-based components to fetch data from third-party APIs such as Geonames and OpenWeather.

### What I enjoyed 
* Using a wide range of APIs to fetch data
* Working on a creative project

### What I struggled with
* Debugging due to limited API calls
* Setting up Leaflet.js to display the map bounds

### What I would improve
* Add hourly forecasting
* Add additional currencies to the currency converter to convert from not just USD

## Portfolio Project #2: Company Directory
The second portfolio project, "Company Directory," demanded a more comprehensive approach as it necessitated the creation of a user requirements document. The project used the following tech stack:

* HTML
* CSS
* jQuery
* Vanilla JavaScript
* PHP
* MySQL
* Bootstrap
The project involved developing a "mobile-first" application for maintaining a company personnel database using MySQL.

### What I enjoyed
* Generating SQL queries to fetch data from the database
* Working on a real-world project

### What I struggled with 
* Database connection issues on the localhost server

### What I would improve 
* Add additional employee information fields, such as telephone number and home address
* Make it so that the user has to log in to view the employee directory

These projects marked significant milestones in my development journey, providing valuable learning experiences and opportunities for growth.
